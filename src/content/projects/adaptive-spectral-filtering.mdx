## The question

Polynomial spectral GNNs like BernNet learn one set of Bernstein filter coefficients and share it across every graph in a dataset. We asked whether making those coefficients a function of each input graph actually helps, and set out to answer it with a comparison strict enough to trust.

## What we built

Two models that drive the identical Bernstein operator inside a GINE backbone. They differ only in where the coefficients come from:

- **Fixed (baseline):** one learned coefficient vector, shared by every graph.
- **Adaptive:** a small MLP reads a multi-scale diffusion signature of the graph and outputs one coefficient vector per graph.

## Making the comparison fair

The part I'm proudest of is the matched initialisation. The adaptive controller's last layer starts at zero weights with a bias chosen so it outputs all ones, which is exactly the all-pass filter the fixed model also starts from. At step 0 the two models are numerically identical. Any adaptivity the model shows, it had to learn.
